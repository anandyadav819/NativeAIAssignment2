# Mock Payment Gateway Implementation

## Overview
Added a mock payment gateway to simulate real-world payment processing scenarios including successes, failures, and various error conditions.

## Components Created

### 1. IPaymentGateway Interface
**Location**: `Order.Application/Services/IPaymentGateway.cs`

Defines the contract for payment gateway implementations:
```csharp
Task<PaymentResult> ProcessPaymentAsync(
    Guid orderId,
    decimal amount,
    string paymentMethod,
    CancellationToken cancellationToken = default);

Task<RefundResult> RefundPaymentAsync(
    string transactionId,
    decimal amount,
    CancellationToken cancellationToken = default);
```

### 2. MockPaymentGateway Implementation
**Location**: `Order.Infrastructure/Services/MockPaymentGateway.cs`

Features:
- ✅ **Simulates network latency** (100-500ms for payments, 100-300ms for refunds)
- ✅ **Validates payment amounts** (must be > 0)
- ✅ **Validates payment methods** (CreditCard, DebitCard, PayPal, Wallet, UPI)
- ✅ **Random failure simulation** (10% failure rate for payments, 5% for refunds)
- ✅ **Multiple error scenarios**:
  - Insufficient funds
  - Card declined by bank
  - Transaction timeout
  - Payment gateway error
- ✅ **Generates realistic transaction IDs** (method-specific prefixes)

### 3. Updated ProcessPaymentCommandHandler
Now uses the payment gateway for actual payment processing:
- Calls `_paymentGateway.ProcessPaymentAsync()`
- Handles success/failure responses
- Stores gateway-generated transaction ID
- Returns transaction ID in response

## Updated API

### Process Payment Endpoint

**Before**:
```http
POST /api/orders/{id}/payment
{
  "paymentMethod": "CreditCard",
  "paymentTransactionId": "TXN123456789"  // Required
}
```

**After**:
```http
POST /api/orders/{id}/payment
{
  "paymentMethod": "CreditCard"  // Transaction ID generated by gateway
}

Response 200 OK:
{
  "message": "Payment processed successfully",
  "transactionId": "CC-20231228120530-abc123def456"
}

Response 400 Bad Request:
{
  "error": "Insufficient funds"
}
```

## Supported Payment Methods

1. **CreditCard** - Transaction ID prefix: `CC-`
2. **DebitCard** - Transaction ID prefix: `DC-`
3. **PayPal** - Transaction ID prefix: `PP-`
4. **Wallet** - Transaction ID prefix: `WL-`
5. **UPI** - Transaction ID prefix: `UPI-`

## Payment Flow

```
1. Client → POST /api/orders/{id}/payment
   ↓
2. OrdersController → ProcessPaymentCommand
   ↓
3. ProcessPaymentCommandHandler → IPaymentGateway.ProcessPaymentAsync()
   ↓
4. MockPaymentGateway simulates payment processing
   ↓ (90% success rate)
5a. SUCCESS: Generate transaction ID → Order.ConfirmPayment()
   OR
5b. FAILURE: Return error → Order.MarkPaymentFailed()
   ↓
6. Response to client with result
```

## Error Scenarios

The mock gateway simulates various real-world failures:

| Error | Probability | Error Code |
|-------|------------|------------|
| Insufficient funds | ~2.5% | `INSUFFICIENT_FUNDS` |
| Card declined | ~2.5% | `CARD_DECLINED` |
| Transaction timeout | ~2.5% | `TIMEOUT` |
| Gateway error | ~2.5% | `GATEWAY_ERROR` |
| Invalid amount | Always | `INVALID_AMOUNT` |
| Unsupported method | Always | `UNSUPPORTED_METHOD` |

## Refund Functionality

The gateway also supports refunds (for future use):

```csharp
var refundResult = await _paymentGateway.RefundPaymentAsync(
    transactionId: "CC-20231228120530-abc123def456789",
    amount: 50.00m,
    cancellationToken);

// 95% success rate
if (refundResult.IsSuccess)
{
    Console.WriteLine($"Refund successful: {refundResult.RefundId}");
}
```

## Configuration & Customization

### Adjusting Failure Rate
Edit `MockPaymentGateway.cs`:
```csharp
private const double FailureRate = 0.1; // Change to adjust failure probability
```

### Adding New Payment Methods
Edit `MockPaymentGateway.cs`:
```csharp
var validMethods = new[] { 
    "CreditCard", "DebitCard", "PayPal", "Wallet", "UPI",
    "NewMethod"  // Add here
};
```

And update prefix generation:
```csharp
var prefix = paymentMethod.ToUpper() switch
{
    "NEWMETHOD" => "NM",
    // ... existing cases
    _ => "TXN"
};
```

## DependencyInjection

The gateway is registered in `Order.Infrastructure/DependencyInjection.cs`:
```csharp
services.AddScoped<IPaymentGateway, MockPaymentGateway>();
```

To replace with a real gateway (Stripe, PayPal, etc.):
1. Create new implementation: `StripePaymentGateway : IPaymentGateway`
2. Update registration: `services.AddScoped<IPaymentGateway, StripePaymentGateway>()`
